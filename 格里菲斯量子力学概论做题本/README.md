## 编译

在本目录中使用包含 ctex 和 TikZ 的 TeX Live 或 MiKTeX，运行两次：

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```
