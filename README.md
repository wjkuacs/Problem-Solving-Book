## 仓库结构
每本书一个目录（如 `舒幼生力学做题本/`），内部：

| 路径 | 说明 |
|---|---|
| `main.tex` | 全书入口，编译即得成品 PDF |
| `chapters/`（或 `chapter/`） | 各章题目 `.tex` |
| `figures/` | 原书插图，按题号命名（`fig_x_y_z.jpg`） |
| `tikzfigs/` | 按原图重绘的 TikZ 图，用于原图不清时对照 |

## 编译
```bash
cd <做题本目录>
xelatex -interaction=nonstopmode main.tex   # 跑两遍
```

做题本的制作流程（MinerU 解析 → 提取 → 生成章节 → 编译）见 `CLAUDE.md`。
