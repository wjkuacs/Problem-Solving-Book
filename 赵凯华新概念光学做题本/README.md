## 文件

- `main.tex`：主文件、页式、题目与插图宏。
- `chapters/chapter1.tex` 至 `chapter7.tex`：逐章题目，可直接编辑。
- `tikzfigs/fig_章_题.tex`：独立 TikZ 题图，可直接编辑。
- `build_figures.mjs`：题图生成器。若用它重新生成，会覆盖 `tikzfigs/` 中的对应文件；需保留图形修改时请同步修改生成器。
- `build.ps1`、`.latexmkrc`：XeLaTeX 编译入口。
- `extract_report.json`：题数、题号、待核信息。
- `source_manifest.json`：原始截图文件名与 SHA-256 校验值。截图不参与编译。

## 编译

安装带有中文字体和 TikZ 的 TeX Live 或 MiKTeX，选择 **XeLaTeX**。使用自带 Fandol 字体，不要求安装商业中文字体。

在本文件夹运行：

```powershell
.\build.ps1
```

或运行：

```powershell
latexmk -xelatex main.tex
```

结果为 `main.pdf`。PDF 内含章节与逐题书签。生成题图仅在需要时运行 `node build_figures.mjs`；正常编译无需 Node.js。
