## 编译

使用包含中文支持和 TikZ 的 TeX Live 或 MiKTeX，以 XeLaTeX 编译。字体采用 TeX 发行版自带的 Fandol，不依赖系统中文字体。

在本目录运行：

```powershell
.\build.ps1
```

或：

```powershell
latexmk -xelatex main.tex
```

源码包包含全部编译所需的本项目文件；解压后在 `main.tex` 所在目录运行以上命令。
