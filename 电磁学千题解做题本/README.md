## 操作步骤

### 1. 校订题干和物理符号

- 从对应的章节文件开始，核对题号和顺序。修复扫描提取造成的断字、断行、重复片段、游离图注和明显的录入错误。
- 若发现题干截断、公式或条件疑似残缺，先去 [Mineru转化后/](Mineru转化后/) 中对应的 Markdown 文件核对原文并补全；仍无法确认时再保留原文并记录待核对处。
- 逐处判断物理量的含义。电场强度、位矢、电偶极矩、电流密度和单位法向量等矢量统一用 `\vec`。有下标时将下标写在箭头命令之外，例如 `\vec{E}_1`。
- 保留标量、分量及大小的原记号。例如 `\vec{E}` 表示电场强度矢量，`E` 表示其大小，`E_x` 表示其分量。电流 `I` 即使带参考方向或正负号，仍按标量处理。矢量点积写成 `\vec{j}\cdot\vec{E}`，大小平方写成 `j^2` 或 `E^2`。

### 2. 核对图号并筛选、补全缺图

- 先从题干列出引用的图号和子图号，再对照章节中的插图、原图和提取记录。图注、独立残留的子图编号以及解答中的图号应先与题干区分。
- 遇到题干只点名某一子图时，保留该子图。题干明确要求比较多幅子图时，逐幅保留。遇到图注错位或扫描文件名与题号冲突时，以题意、原图内容和图注的交叉核对为准。
- 删除题干未引用的插图块及其图注。把原始扫描图留在 `figures/` 中供复查。
- 若题干中引用了图号，但章节源码和 `figures/` 中缺少对应图片，需回查 [Mineru转化后/](Mineru转化后/) 里的 Markdown 文件（如已被历史过滤误删，也可同步对照 Git 历史），按图注与题意定位对应图片并下载/检出保存到 `figures/` 后纳入重绘；若一道题明确引用前题的图，可在本题页面调用同一份 TikZ 源并保留原图号。确实找不到对应原图时，保留题干引用并把图号记入该章缺图清单。

### 3. 用 TikZ 重绘

- 在 `tikzfigs/chapterN/` 下按题图编号保存文件。单图可用 `fig_4_1_2.tex`，子图可用 `fig_4_1_8_1.tex`。沿用已有线型、箭头、尺寸线和电路元件样式。
- 与原图逐项核对。几何图检查方向、点名和尺寸，电路图检查电源极性、开关、支路连接以及交叉处是否相接。图内矢量沿用题干的 `\vec` 写法。
- 把选中的扫描图替换成章节绘图命令，保留与正文对应的图注。例如第四章第 4.1.10 题的插图块如下。

```latex
\begin{center}
    \EMfourthDiagram{4_1_10}
\end{center}
\captionof*{figure}{图4.1.10(1)}
```

后续章节可沿用已有绘图命令的结构，在 `main.tex` 中接入该章的图源路径。多幅子图应在同一题页内一起排版。

### 4. 按题分页

把一道题的完整题干、公式、图和图注放在同一页，随后用 `\vfill` 留出做题空间，再用 `\newpage` 换页。整理旧章时，先移除章内旧的两题一页分页标记，再按每题重设，包含该章末题。若某题溢出，先检查插图尺寸及留白，再核对下一题是否仍从新页开始。

新整理的章节从现有章节源文件接着编辑。重新运行提取或生成脚本前，应确认它们的输出目标，以免覆盖手工整理后的题干和插图引用。

### 5. 编译与验收

在做题本目录中执行以下命令。需要可运行 XeLaTeX 的 TeX 发行版，以及文档使用的 `ctex`、TikZ、`adjustbox` 等宏包。

```powershell
xelatex -synctex=1 -interaction=nonstopmode -halt-on-error main.tex
```

编译完成后，按以下项目核对。

- 整章的题数、题号和顺序与整理前一致。每一页只出现一道新题，题干和插图没有跨页，下一章从新页开始。
- 正文中的每个 TikZ 引用都能找到源文件。每张保留的图都有题干引用，缺图清单可用来定位未找到原图的题。
- 渲染查看新绘插图及其在正文中的版面，检查文字、符号、箭头、接点和图注的可读性。
- 更新整本 `main.pdf`。如需单独审图，可以另编译本章的插图合集。
