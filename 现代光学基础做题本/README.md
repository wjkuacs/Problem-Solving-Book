## 编译

安装包含 XeLaTeX、ctex 和 TikZ/PGF 的 TeX Live 或 MiKTeX。在本目录下执行两次：

```powershell
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```

也可使用：

```powershell
latexmk -xelatex main.tex
```

中文字体由 ctex 根据系统选择。解压源码包后保留主文件、chapters 和 tikzfigs 的相对目录结构即可编译，无需额外图片文件。
