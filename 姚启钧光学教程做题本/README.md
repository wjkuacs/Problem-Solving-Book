## 目录结构

- `main.tex`：主文档（`ctexbook`，A4 纸，每页两题，自动目录与书签）
- `main.pdf`：编译生成的完整 PDF（99 页）
- `chapters/chapter1.tex` ～ `chapter8.tex`：各章习题源码
- `tikzfigs/fig_*.tex`：26 幅 TikZ 矢量题图源码
- `build.ps1`：一键编译脚本

## 编译方式

需要 TeX Live（`xelatex` + `ctex` + `tikz`）：

```powershell
.\build.ps1
```

或手动执行两遍：

```bash
xelatex -interaction=nonstopmode -halt-on-error main.tex
xelatex -interaction=nonstopmode -halt-on-error main.tex
```
