## 阅读与编辑

- [完整 PDF](main.pdf)
- [LaTeX 源码包](sources.zip)
- `main.tex`：封面、目录、页眉、题目及题图样式。
- `chapters/chapter1.tex` 至 `chapter11.tex`：各章题目。
- `tikzfigs/`：题图源文件；图 2.1 和图 6.1 共用 `stern_gerlach.tex`。
- `extract_report.json`：题数、来源及待补充材料记录。

## 编译

安装含中文支持和 TikZ 的 TeX Live 或 MiKTeX，使用 XeLaTeX。采用 TeX Live 自带 Fandol 字体。

在本目录运行：

```powershell
.\build.ps1
```

或：

```powershell
latexmk -xelatex main.tex
```
